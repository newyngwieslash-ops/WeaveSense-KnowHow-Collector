# 画布节点覆盖层命中边界

## 目标与范围

共享CanvasNode右上状态轨道可显示资源编号、锁定状态、存储位置、图片组展开/收起、主图与图层控制。修复装饰容器截获数据源预览点击的问题，所有调用方复用共享入口，无API、元数据、数据流或数据库变化。

## 装饰与控件

状态轨道及其空隙默认不接收指针，编号与锁图标继续可见、保持穿透；不隐藏编号或无差别恢复所有后代的指针事件。现有存储位置说明保留悬停命中；图片组、可见主图和图层管理按钮明确接收自身范围内的指针，隐藏主图按钮仍不接收事件。只读、locked及已有动作显示条件不改变。

## 顶栏和预览

数据源与逻辑节点仅在存在状态轨道时，在共享内容容器预留最小顶部状态空间，使编号与顶栏文字不相互覆盖。无轨道不添加空白，其他节点保持原布局。不改变节点持久尺寸或引入新偏好；剩余正文沿原有滚动/预览规则显示。

存在编号的数据源，其预览/源码按钮中心鼠标首次点击即双向切换，Enter/Space和aria-pressed仍正确；无需寻找边缘图标。相同四条输入在预览与源码间保持，切换不触发节点拖拽、框选、生成或数据丢失。
